### Como rodar o projeto (bem simples)

1. Instale as dependências:

```bash
npm install
```

2. Inicie o projeto:

```bash
npm start
```

3. Abra no dispositivo que quiser:

```bash
npm run android
```

```bash
npm run ios
```

```bash
npm run web
```
